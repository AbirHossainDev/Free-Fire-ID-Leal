## 🎮 About The Project

*Free Fire ID Leaf* is a modern web project created to display
Free Fire related information in a clean and attractive interface.

The project focuses on:

- 🎨 Modern UI
- 📱 Mobile responsive design
- ⚡ Fast loading
- ✨ Smooth visual effects
- 🧩 Simple structure
- 🌐 GitHub Pages support
